# Natural Effects — Portfolio package

这份文件夹把作品整理为一项持续进行的 creative coding research：从自然材料的身体记忆出发，用交互实验探索重力、运动、质感和声音，并研究如何将这些经验发展成可复用的创作工具。

## 文件

- `01-portfolio-narrative.md`：英文作品页草稿，按 Opening → Starting observation → Material studies → Simulation studies → From experiments to tools → Ongoing research 展开。
- `02-toolkit-direction.md`：工具化方案，区分已有代码与待开发能力。
- `03-media-plan.md`：作品页需要的影像、演示和实验记录清单。

## 当前边界

这是进行中的创作研究与原型，不是经过物理验证的模拟器，也尚未完成正式用户研究。摄像头追踪的流畅度、凝露自然度和声音匹配仍需实测。投影已有技术原型方向，真实墙面体验仍待测试。

在线作品：https://naturaleffects.vercel.app/

## 使用建议

先录制当前真实交互，再根据录像修订文案中关于效果的描述。工具化部分使用 “toward / proposed / in development”，不要将设想的编辑器和统一接口写成已实现的功能。技术状态随项目更新。
